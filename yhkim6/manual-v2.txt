올바른 버튼 실행 순서
버튼의 기능에 따라 실행 순서가 정해져 있습니다. 올바른 작업 흐름은 다음과 같습니다.

데이터 업로드: 학습용 이미지 업로드 및 테스트용 이미지 업로드를 통해 필요한 파일을 먼저 업로드합니다.

학습 시작 버튼 클릭: 모델 학습을 시작합니다. 이 단계에서 pseudo_zero_labels.csv 파일이 생성되고 best.pth 가중치 파일이 저장됩니다.

분석 시작 버튼 클릭: 학습된 모델(best.pth)을 사용하여 업로드된 테스트 이미지를 분석합니다.

분석 결과 보기 버튼 클릭: 분석이 완료된 후, 결과를 그래프와 지표로 확인합니다.

따라서, 학습 시작 버튼을 먼저 눌러 모델을 훈련시킨 후에 분석 시작 버튼을 눌러야 오류 없이 결과를 확인할 수 있습니다. 분석 시작은 학습된 모델이 없으면 실행되지 않습니다.
